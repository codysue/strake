# Strake

A small, accessible React component library with a **visible token pipeline** and
an **agent-queryable design-system API**.

Strake is a portfolio-grade design system, built to be read as much as used. It is
deliberately compact — ten components — but every one is real: keyboard-operable,
correctly ARIA-labelled, and driven entirely by design tokens.

## The three ideas it demonstrates

1. **A token pipeline you can watch move.** A single W3C DTCG source of truth
   compiles through Style Dictionary into CSS custom properties, a Tailwind theme
   fragment, and TypeScript constants. Change one value in `tokens/src`, run one
   command, and the change propagates to every output. CI fails if the committed
   outputs ever drift from source. See **Foundations → Tokens**.

2. **Accessibility as engineering, not decoration.** The Dialog and Command menu
   use a hand-built focus trap (Tab wrapping, initial focus, restore-on-close);
   the Select is a full listbox with type-ahead and roving focus; the DataTable
   is keyboard-navigable with `aria-sort`. Toggle the **Theme** control in the
   toolbar — light and dark both come from the same semantic tokens.

3. **The design system as a queryable API.** A companion read-only MCP server
   (`@codysue/strake-mcp`) exposes the same tokens and component metadata as
   tools an agent can call. The design system stops being a static artifact and
   becomes something an agent can read.

## Components

Button · TextField · Switch · Select · Tooltip · Popover · Dialog ·
Command menu (⌘K) · Toast · DataTable

## Try it

- Flip the **Theme** toolbar control to see the token-driven dark mode.
- Open the **Patterns → Motion & Interaction** story and press **⌘K**.
- Tab through any component — the focus ring is one token, defined once.
